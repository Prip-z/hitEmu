# RUST
Эмулятор создавался на чистом желании познакомиться с процессом эмулирования железа консоли и как практика языка Rust. 
# Запуск
* Путь для ROM-а захардкожен в main.rs. Да, неправильно, да, не круто. Когда-нибудь возможно и то не факт, я сделаю эмулятор юзабельным
* Поэтому нужно менять путь к рому в переменной let cartidge_data = cartridge::Cartridge::parse_rom("Путь\\К\\Файлу"), и запуск через `cargo run`
# Техническая реализация
* Кроме описанных выше проблем, в эмуляторе только начата работа над поддержкой звука, так что марио хоть и прыгает, но звуков не издаёт
* Время в марио утекает быстро, так как фпс-ы я не ограничил(с этим были проблемы)
* Поддержка второго геймпада отсутствует
# Управление
* Стрелочки ВВЕРХ/ВНИЗ/ВЛЕВО/ВПРАВО отвечают за крестовину
* ПРОБЕЛ за SELECT
* Z и X за A и B соответственно
* ENTER за START
# Совместимость
* Проверял только Марио и Donkey Kong, т.к они поддерживают 0-ой маппер, другие мапперы я просто не реализовывал
